# Salient

即時戰略對局遊戲。地圖以真實行政區界線構成，台灣是第一張，之後會加入世界其他板塊。開發中。

## 執行方式

雙擊 `start-game.bat`，或：

```bash
npm install
npm run dev
```

瀏覽器開啟 http://localhost:5173

要玩**連線對戰**的話，另外開一個終端機跑中繼伺服器：

```bash
npm run relay
```

兩邊都在同一台機器上時這樣就夠了。要跟遠方的人連線得把中繼部署出去，見 [server/README.md](server/README.md)。

## 指令

| 指令 | 說明 |
|---|---|
| `npm run dev` | 開發伺服器 |
| `npm run build` | 打包production版本 |
| `npm test` | 執行全部測試（vitest，325項） |
| `npm run relay` | 連線對戰的中繼伺服器（PVP 對局需要，預設 ws://localhost:8787） |
| `npm run relay:deploy` | 把中繼部署到 Cloudflare Workers，見 [server/README.md](server/README.md) |
| `npm run lint` | 靜態檢查（oxlint） |
| `node scripts/build-map-data.mjs` | 重新產生地圖資料（改動 `scripts/subregions.mjs` 後需執行） |
| `node scripts/analyze-disconnected.mjs` | 檢查是否有區塊由不相連的土地組成 |

## 玩起來是什麼樣子

- **金錢不由領土產生，而由村民產生**。村民是站在地圖上的人：在核心生成，可以行軍，0戰力1血量，走進敵軍就是單方面的屠殺
- **建築本身不產出任何東西**，產出的是在裡面工作的村民。空的商鋪就是一間空屋；每位進駐村民 +2%，滿編10人 +20%。所以經濟有物流，也有可以被端掉的軟肋
- **行軍、攻城、佔領是三道獨立命令**，下在你想要的那塊地上。地上有對方建築就不能直接佔領——打掉建築才拿得到地，裡面的村民也一起沒了
- **部隊與村民共用一個人口上限**，所以養兵會永久壓低收入天花板
- **路線只看地形**。封路的只有中央山脈與敵方關隘；敵軍不會讓你繞道，走到就打——攔截正是這樣成立的
- 資重、戰爭迷霧、穿山點、核心血量、機械化部隊各自是獨立的一層限制

## 目前進度

**三種對戰模式都能玩**：單人對戰電腦、玩家連線對戰、以及看兩台電腦互打。

| | |
|---|---|
| 地圖 | 63 個真實子區域、5 個穿山點、中央山脈、2D／3D 兩種畫法 |
| 經濟 | 村民投資循環、建築進駐、糧食與人口上限、30 項科技樹 |
| 軍事 | 步兵四階與逐級升級、戰車／迫擊炮／偵查兵、多輪消耗戰、資重補給與資重車、砲擊、戰壕與關隘 |
| 情報 | 戰爭迷霧、偵查兵、無人機、反偵察 |
| 對手 | 本地 AI 三種難度：會發展經濟、集結軍隊、構築工事、真的來打你 |
| 連線 | 房間碼、中繼伺服器、共用開局設定、主機權威、迷霧過濾的快照、客機本地預測、斷線自動重連、重新整理後回到對局 |
| 社交 | 大廳與對局中的聊天（同一段對話跨越開打）、交換顏色與起始位置、房主改動時客機收到說明 |
| 重播 | 每局自動存檔，一局幾 KB，可下載給別人看；可拖動進度條、可從任一點接手續玩 |

**尚未實作**：單人對局重新整理後會結束、建築修復（只有駐守村民的自動搶修）、接手續玩的那一局不會被錄下

完整設計與進度見 **[docs/game-design.md](docs/game-design.md)** — 該文件是設計的單一真實來源。

## 專案結構

```
src/engine/     遊戲規則的唯一來源（純TypeScript，不依賴React，270個測試獨立覆蓋）
src/ai/         本地AI席位。在引擎外面，只能下人類也能下的命令（20個測試）
src/match/      對局的組成、連線與重播：席位、通訊協定、連線、指令錄影（15個測試）
server/         連線對戰的中繼伺服器（Cloudflare Worker，可獨立部署，不含遊戲程式碼）
src/ui/         介面元件。介面不含任何規則
src/settings/   設定與多語系
scripts/        地圖資料建置與分析工具
docs/           設計文件
```

規則只住在 `src/engine/` 裡。介面問引擎「這件事能不能做」（`*Rejection()`）而不自己判斷，AI 也走同一套公開命令——引擎不知道座位後面是人、是程式、還是一條網路連線。連線對戰接上去的時候，引擎一行都沒有改。

引擎**以固定 0.1 秒推進，而且沒有任何隨機**。這件事付了三次錢：同一局在快慢不同的機器上結果一致、連線兩端對得起來、而且**錄下指令流就等於錄下整場對局**——所以一份重播是幾 KB 的決策，不是一串狀態，連 AI 都是重播時重新想一遍而不是把結論記下來。
