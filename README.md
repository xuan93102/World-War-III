# Salient

即時戰略對局遊戲。地圖以真實行政區界線構成，台灣是第一張，之後會加入世界其他板塊。開發中。

## 執行方式

雙擊 `start-game.bat`，或：

```bash
npm install
npm run dev
```

瀏覽器開啟 http://localhost:5173

## 指令

| 指令 | 說明 |
|---|---|
| `npm run dev` | 開發伺服器 |
| `npm run build` | 打包production版本 |
| `npm test` | 執行引擎測試（vitest） |
| `npm run relay` | 連線對戰的中繼伺服器（PVP 對局需要，預設 ws://localhost:8787）。部署方式見 [server/README.md](server/README.md) |
| `npm run lint` | 靜態檢查（oxlint） |
| `node scripts/build-map-data.mjs` | 重新產生地圖資料（改動 `scripts/subregions.mjs` 後需執行） |
| `node scripts/analyze-disconnected.mjs` | 檢查是否有區塊由不相連的土地組成 |

## 玩起來是什麼樣子

- **金錢不由領土產生，而由村民產生**。村民是站在地圖上的人：在核心生成，可以行軍，0戰力1血量，走進敵軍就是單方面的屠殺
- **建築本身不產出任何東西**，產出的是在裡面工作的村民。空的商鋪就是一間空屋；每位進駐村民 +2%，滿編10人 +20%。所以經濟有物流，也有可以被端掉的軟肋
- **行軍、攻城、佔領是三道獨立命令**，下在你想要的那塊地上。地上有對方建築就不能直接佔領——打掉建築才拿得到地，裡面的村民也一起沒了
- **部隊與村民共用一個人口上限**，所以養兵會永久壓低收入天花板
- 資重、戰爭迷霧、穿山點、核心血量、機械化部隊各自是獨立的一層限制

## 目前進度

**已實作**：地圖（63個真實子區域、5個穿山點）、地塊與中立守軍、村民經濟與建築進駐、建築系統、兵種與升級、行軍與多輪消耗戰、資重補給與資重車、30項科技樹、機械化部隊與砲擊、偵查與戰爭迷霧、臨時營地、戰亂狀態、核心血量與連地、本地AI（三種難度）、電腦內戰觀戰、**連線對戰**（房間碼、中繼伺服器、共用開局設定、主機權威、迷霧過濾的快照、客機本地預測、斷線自動重連）、**存檔與重播**（錄指令流，幾KB一局）、對局流程（主選單／PVE設定／暫停／勝負結算／三語系／2D3D地圖）

**尚未實作**：重新整理頁面後回到連線對局、建築修復（只有駐守村民的自動搶修）

完整設計與進度見 **[docs/game-design.md](docs/game-design.md)** — 該文件是設計的單一真實來源。

## 專案結構

```
src/engine/     遊戲規則的唯一來源（純TypeScript，不依賴React，236個測試獨立覆蓋）
src/ai/         本地AI席位。在引擎外面，只能下人類也能下的命令
src/match/      對局的組成、連線與重播：席位、通訊協定、連線、指令錄影
server/         連線對戰的中繼伺服器（可獨立部署，不含遊戲程式碼）
src/ui/         介面元件。介面不含任何規則
src/settings/   設定與多語系
scripts/        地圖資料建置與分析工具
docs/           設計文件
```

規則只住在 `src/engine/` 裡。介面問引擎「這件事能不能做」（`*Rejection()`）而不自己判斷，AI 也走同一套公開命令——引擎不知道座位後面是人還是程式，所以之後接上連線對手時引擎不用改。

## 地圖資料來源

地理形狀來自 [taiwan-atlas](https://github.com/dkaoster/taiwan-atlas)（內政部鄉鎮市區界線資料，MIT授權）。`src/engine/mapData.generated.ts` 為自動產生，請勿手動編輯。
